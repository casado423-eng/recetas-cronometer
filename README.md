# Recetas para Cronometer

Este directorio contiene recetas con estructura Recipe de Schema.org para facilitar su importación mediante el Recipe Importer de Cronometer.

## Publicación en GitHub Pages

1. Crea un repositorio, por ejemplo `recetas-cronometer`.
2. Sube el contenido de esta carpeta manteniendo las carpetas de cada receta.
3. Activa GitHub Pages desde Settings → Pages → Deploy from a branch → `main` / root.
4. Las recetas quedarán disponibles en URLs del tipo:
   `https://TUUSUARIO.github.io/recetas-cronometer/pasta-lentejas-pollo-queso/`

Después, pega cada URL en el importador de recetas de Cronometer.

## Importante
Cronometer puede emparejar un ingrediente con un alimento distinto al que usas. Tras importar, revisa especialmente HSN, yogur, queso y pasta de legumbres y selecciona tus productos exactos.
